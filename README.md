# Transformation VFX & Chant Direction

把“普通人下定决心保护某人／面对怪物”写成一段有情绪因果的原创英雄变身：**决心 → 力量回应 → 真人「変身！」→ 系统唱名 → 分级特效 → 重量落地与守护完成**。

![一图流：当决心回应力量](poster.png)

## 适用场景

- 原创蒙面英雄、变身桥段、分镜和 AI 视频提示词
- 需要明确区分真人喊出的日文「変身！」与装置独立唱名
- 需要把特效写成“来源 → 路径 → 接触/锁定 → 后果 → 衰减”
- 需要宏大但不遮脸、口型、被保护者和完整英雄轮廓的收束镜头

## 核心规则

1. 先拍普通人的恐惧、犹豫与呼吸，再让他主动挡到危险与被保护者之间。
2. 决心必须通过动作发生；力量从胸口／核心回应已经做出的选择。
3. 真人只清楚喊一次 **「変身！」**，装置和旁白不能代喊或重复。
4. 系统唱名独立于真人声音，每一句都绑定一个可见动作和下一状态。
5. 特效按五级升级：待机光、启动光门、分件光轨、锁止爆发、余波收束。
6. 变身完成要有稳定站姿、重量反馈、环境回应，以及被保护者的安全终态。

## 安装

适用于支持 `SKILL.md` 的编码 Agent：

```bash
npx skills add https://github.com/q2522879285-source/transformation-vfx-chant-direction
```

也可以把本仓库目录复制到客户端的 Skill 目录，确保最终路径为：

```text
<Skill 目录>/transformation-vfx-chant-direction/SKILL.md
```

## 直接使用

```text
用 $transformation-vfx-chant-direction，设计一个原创英雄变身场景。
普通人先害怕，但为了保护身后的人主动挡住怪物；他宣告守护后，清楚喊一次「変身！」。
请写出独立的系统唱名、每句对应的视觉动作、五级特效因果链、身体重量反馈和最终守护状态。
```

## 边界

本 Skill 只负责情绪决断、力量回应、唱名时序与变身特效的交叉面；机械结构、通用特效物理、声音混音和平台语法交给对应的专业 Skill。内容使用原创机制与措辞，不复制任何既有作品的角色、口号、旋律或镜头。
